# ageRange
Indicates that this resource is recommended as being suitable for, or is targeted at, a specific age range.

This property can be used on: [`schema:Course`](https://schema.org/Course), [`schema:Event`](https://schema.org/Event), [`schema:Offer`](https://schema.org/Offer), [`schema:Organization`](https://schema.org/Organization)

This property may include the values: [`schema:QuantitativeValue`](https://schema.org/QuantitativeValue)

For more information, see the [developer documentation](https://developer.openactive.io/data-model/types/).
