# activity
Specifies the physical activity or activities associated with this resource.

This property can be used on: [`schema:Course`](https://schema.org/Course), [`schema:Event`](https://schema.org/Event), [`oa:FacilityUse`](https://openactive.io/FacilityUse), [`schema:Organization`](https://schema.org/Organization)

This property may include the values: [`skos:Concept`](http://www.w3.org/2004/02/skos/core#Concept)

For more information, see the [developer documentation](https://developer.openactive.io/data-model/types/).
